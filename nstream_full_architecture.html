NStream — complete product architecture

A unified AI-powered media platform serving three distinct customer segments through a single cloud-GPU backend written entirely in Rust.

Customer segments and products

Studios and streaming platforms
Netflix, Disney, Prime Video, independent studios. Offline batch processing of full-length films and series.
Live streamers
Twitch, YouTube Live, Kick creators. Real-time enhanced streams with up to 5-minute processing delay.
Content creators
YouTube, TikTok, Instagram. Upload-and-dub workflows with selective scene processing and ad sync.

Full feature list

Dubbing and voice

Multilingual dubbing Rust
Any source language to any target language. 100+ language pairs. Parallel language processing from a single job submission.
Expressive voice cloning
High-fidelity clone of original actor voice. Prosody, emotion, breathing, and micro-pauses preserved. Feels like the actor spoke the target language natively.
Forced alignment
Phoneme-level audio alignment using Whisper. Ensures dubbed audio timing matches scene cuts and character mouth movements frame-accurately.

Lip sync and face

Frame-accurate lip sync
AI-driven lip and mouth alteration matched to dubbed audio. Temporal consistency maintained across full 2-hour features without drift.
Multi-camera lip sync
Handles multiple camera angles simultaneously. Consistent face alteration across cuts and angle switches in live and batch modes.
Face preservation
Only the lip and jaw region is modified. Eyes, skin, hair, and non-mouth facial features remain untouched to preserve performance integrity.

Live stream mode

5-minute buffer pipeline Rust
Sliding ring buffer holds up to 5 minutes of raw stream. Enables full AI processing quality on live content without real-time latency constraints.
AI video upscaling
Real-time upscaling from 1080p to 4K-quality detail recovery. Adaptive quality based on streamer GPU tier — shader-fast on low-end, AI-grade on high-end.
Cinematic visual effects
Automatic cinematic LUT grading, bloom and lens effects, simulated depth-of-field, film grain, and motion-reactive particle overlays.
Dynamic sound effects
AI event detection triggers Foley-style audio injection. Environmental reverb, impact sounds, background ambience layers, and EBU R128 loudness compliance.
Multi-camera live editing
Ingests simultaneous feeds from multiple cameras. AI selects best angle automatically based on motion, face detection, and scene energy. Director override via API.
OBS and Streamlabs integration
Connects via RTMP or SRT push from streaming software. Returns enhanced stream as a virtual camera and audio device. One-click setup for streamers.

Studio batch mode

Fast batch processing Rust
Target under 24 hours per feature film per language on a single GPU node. Parallel multi-language jobs scale linearly without quality loss.
Video enhancement
Upscaling, noise reduction, shaky-footage stabilization, intelligent sharpening, and HDR-aware color correction for studio-grade output.
Audio post-production
Full audio polish pass: mixing, loudness normalization, subtle Foley insertion matched to dubbed voice, and room acoustic simulation per scene.
NLE-ready export
Output in ProRes and DNxHR with EDL and XML sidecar files. Drops directly into DaVinci Resolve and Premiere timelines with zero manual alignment.
QC report
Automated NStream Certified report per job: lip-sync error in frames, voice naturalness MOS score, PSNR for video, EBU R128 compliance, and re-take rate estimate.
Studio API
REST API for direct integration into studio workflows. Submit jobs, poll status, download outputs, and receive webhook notifications on completion.

Creator tools

Upload and dub
Upload any video. Select target languages. Receive parallel dubbed outputs. Optimized for YouTube, TikTok, Instagram Reels, and Shorts formats.
Selective scene dubbing
Mark specific timestamp ranges on a timeline. Only those scenes are processed. Saves cost and time for creators who only need key moments dubbed.
Live ad sync
Pre-dubbed ads inserted at natural pause points. Synced to stream language. Seamless audio and visual transition. Creator earns from localized ad inventory.

Backend architecture — pure Rust

Core crates and responsibilities

nstream-core Rust
Shared types: MediaPayload, Node trait, NStreamError, JobStatus, timestamps, and metadata structs used across all crates.
nstream-dag Rust
DAG executor using petgraph. Topological sort, cycle detection, dependency resolution, and async task dispatch per node.
nstream-ingest Rust
RTMP and SRT server, S3 file intake, multi-camera feed aggregator. Feeds into the ring buffer or batch job queue.
nstream-buffer Rust
5-minute sliding ring buffer for live mode. Disk-backed overflow for large batch jobs. Zero-copy Arc frame passing.
nstream-inference Rust
GPU worker pool. Loads ONNX models via ort. Runs ASR, TTS, lip-sync, upscale, and VFX detection. Batched inference with back-pressure.
nstream-media Rust
FFmpeg bindings via ffmpeg-next. All decode, encode, mux, and filter operations. Hidden behind a MediaDecoder trait for future pure-Rust replacement.
nstream-api Rust
HTTP REST server via axum. Job submission, status polling, webhook dispatch, billing metrics, and creator timeline API.
nstream-observe Rust
Structured logging via tracing. Prometheus metrics per pipeline node. OpenTelemetry distributed tracing. Cost tracking per GPU-second consumed.

Cloud infrastructure

GPU cloud
CoreWeave and RunPod for H100 and H200 GPU nodes. Spot instances for batch jobs. On-demand for live streams. Auto-scale on queue depth.
Job orchestration
Kubernetes with GPU node selectors. PostgreSQL job queue via sqlx. Exactly-once processing with atomic job claiming and timeout-based recovery.
Storage
S3-compatible object storage for input and output media files. Fast NVMe block storage for active job intermediate frames.
Edge ingest
Low-latency RTMP and SRT ingest points close to streamer location. Cloudflare for CDN delivery of enhanced output streams to viewers.

Monetization model

Studios
Per-finished-dubbed-minute pricing per language. Enterprise flat license plus usage for large volume. QC report and NLE delivery included.
Streamers
Monthly subscription tiers by feature set. Free tier with watermark and limited languages. Pro tier unlocks all effects, full lip sync, and 5+ languages.
Creators
Credit-based usage. Pay per scene-minute processed. Ad revenue share from localized ad sync. Subscription option for high-volume creators.
